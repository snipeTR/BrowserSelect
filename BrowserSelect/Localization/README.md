# Localization

BrowserSelect reads its user interface texts from **one file**: `Strings.resx` (English).
English is the default and the fallback language, and currently the only one shipped.

## Pieces

| File | Purpose |
|------|---------|
| `Strings.resx` | Single English source of UI texts (key → text, with a comment for translators) |
| `Strings.Designer.cs` | Strongly-typed accessor: `Strings.Language_Label`, … (regenerated by Visual Studio when the .resx is edited there) |
| `L10n.cs` | `L10n.T("Key")` lookup (falls back to English, then to the key – never throws), `L10n.Apply(lang)`, `L10n.Available()` |
| `Settings.Language` | Selected language tag (default `en`), applied at startup in `Program.Main` |
| Settings window | **Language** drop-down at the bottom left lists English plus every installed translation |

Only `CurrentUICulture` is changed. `CurrentCulture` (number/date parsing used by settings, timestamps and
rules) is never touched, so switching languages cannot change program behaviour.

## Using a text in code

```csharp
using BrowserSelect.Localization;

MessageBox.Show(Strings.Settings_UnsavedChanges, Strings.Settings_UnsavedChangesTitle, MessageBoxButtons.YesNo);
label.Text = L10n.T("Some_Key");            // by key
label.Text = L10n.T("Some_Format", count);  // with string.Format arguments
```

Moving a hard-coded text: add a key to `Strings.resx` (same English text), add the matching property to
`Strings.Designer.cs` (or let Visual Studio regenerate it), replace the literal with `Strings.Key`.
Do not move browser names, URLs, registry paths, rule patterns or other values the program compares.

## Adding a language (later)

1. Copy `Strings.resx` to `Strings.<culture>.resx` (e.g. `Strings.tr.resx`) and translate the `<value>`s.
   Missing keys automatically fall back to English.
2. Add it to `BrowserSelect.csproj`:
   ```xml
   <EmbeddedResource Include="Localization\Strings.tr.resx">
     <DependentUpon>Strings.resx</DependentUpon>
   </EmbeddedResource>
   ```
3. Build: MSBuild produces `tr\BrowserSelect.resources.dll` next to `BrowserSelect.exe`; the installer
   packs every `<culture>\BrowserSelect.resources.dll` automatically.
4. The language now appears in Settings → Language (bottom left). The choice takes effect on the next start.
